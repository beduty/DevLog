# 추가된 내용

1. 사용자가 실제 Entity를 추가하거나 Script(GameCode)를 넣을 수 있도록 MSVC solution 파일을 만든다.
2. 생성한 Solution의 빌드결과가 Game 실행파일이다.
3. 다만, Script추가 내용등이 Level Editor에서 확인해볼 수 있도록 DLL을 만들도록 세팅할 수있게 한다.(GameCode는 Type에 따라서 Exe또는 Dll을 만드는 세팅을 다르게 가져간다.)
